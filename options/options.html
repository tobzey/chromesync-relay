Optional: encrypted shared folder

Writes an AEAD-encrypted blob into a folder you sync yourself (Syncthing, iCloud Drive, …). Required: drop folder + the same pairing secret on both machines. The secret is never hardcoded and never logged. A random non-identifying host id and replay counters are generated and stored in the companion’s local app-state directory (~/.chromesync) on first use — not in the drop folder, never cookies.

Storage

Default is session-only (chrome.storage.session): the API key is cleared when the browser restarts. Enabling this writes it to disk under your browser profile.

When set, the companion shells out to profile-use sync (requires profile-use ≥ 1.0.5 on PATH and BROWSER_USE_API_KEY in the companion environment). The collected cookie array is not sent to the CLI.
